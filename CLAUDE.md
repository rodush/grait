# Shared repository instructions

The shared skill and role catalog is in `docs/agents.md`. Native definitions are generated from `automation/skills/` and `automation/agents.json`.

Read @AGENTS.md, @docs/coding-guidelines.md, and @docs/workflow.md before working. These files contain the shared policy for all harnesses. Do not duplicate their rules here.

For PR review, also read @docs/review-guidelines.md. Review runs in the local harness; publish findings in the GitHub PR UI through the separate reviewer App.
